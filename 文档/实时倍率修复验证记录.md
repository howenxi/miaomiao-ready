# 实时系统倍率修复验证

2026-11-19。用户反馈上一版未解决，已撤回其完成判断。

## 复现与根因
- 卡片内试用句柄可与CUR一致，但卡片外系统光标更大。
- 配置CursorBaseSize写32后，SystemParametersInfoW(0x2028)读到实时48。
- SPI_SETCURSORS(0x57)只重载方案；创建时禁止DPI缩放不等于取消独立的辅助功能实时倍率。
- 对照调用0x2029同步32后，卡片外光标缩小至对应预览尺寸。之前的像素差异不是必须容忍的边缘处理。

## 修正
- 应用：备份原方案/大小配置/实时值 → 写32和第1档 → 同步实时32并读回 → 重载方案 → 应用原生句柄 → 异步通知。
- 恢复与失败回滚：同时恢复配置的原值/类型/是否存在及原实时值；旧备份补缺，保留首次方案。
- 系统副本像素、尺寸、热点全部严格核对，移除2px容差。

## 验证证据
- 最终构建：构建输出-实时倍率最终版。
- --self-test通过，三档试用像素/热点/绘制居中通过。
- 以配置48、第2档、实时48为起点，--integration-test通过；实际25/35/45系统副本像素逐字节一致，结束恢复配置与实时48。
- 旧备份删除新大小字段后，升级并核对原设置通过。
- 独立严格检查三档24个系统副本：24通过，0差异。
- 实际窗口操作大/小/中并点击应用，观察卡片外系统箭头与预览对应，最后选择并应用中35。
