# 猫咪指针生图规则 v1

适用于所有现有和新增猫咪，共八种场景。动作参考用原型正在使用的银渐层成品，猫咪长相用目标猫的照片和已确认的角色图。

指针功能、关键动作、热点及各场景的硬约束必须保留。允许在规则内微调表情、头部倾斜、坐姿角度、爪位和构图比例。以用户确认的两张银渐层抱箭头示例为准：正坐与略侧坐、不同头部朝向和抓握位置都可以，只要仍能看出猫在抱箭头，左上箭尖清楚可点。参考图用来统一动作，不要求逐像素复刻。

| 场景 | 构图与热点 |
|---|---|
| 正常选择 | 猫咪用两只前爪抱住朝左上的箭头，抓握位置可微调。热点在露出的箭尖。 |
| 文字输入 | 左侧短而细的 I 形，右下只露猫头和两只前爪。用银渐层成品校准长度，猫脸避开文字定位区。热点在 I 形中点。 |
| 链接点击 | 猫向左上跃起，伸出一只爪指向点击点。小短线仅作提示，热点在爪尖。 |
| 不可用 | 猫从红色禁止环后探头，两爪搭住环，斜杠完整可见。热点在环中心。 |
| 忙碌中 | 闭眼蜷睡，两只前爪并排，尾巴绕到身前。头顶三块橙色进度标沿弧线排列。热点取主体中心。 |
| 移动画布 | 猫斜向伸出一只展开的大爪，粉色肉垫朝前。热点在大爪中心。 |
| 左右调整 | 正脸低趴，两爪分开搭在横箭杆上，身体横向展开。整只猫（含爪子和尾巴）必须落在左右箭尖之间，两端各留少量余量。尾巴可翘起或弯曲。热点在双箭头中点。 |
| 上下调整 | 猫在竖箭头右侧，两爪扶住箭杆，上下箭尖露出。热点在双箭头中点。 |

## 生成与验收

1. 每只猫先生成正常选择，确认照片里的脸型、花纹、毛长和体态。后续沿用确认过的角色参考。橘猫保留蓬松胸毛，狸花保留额头和四肢条纹，德文保留大耳、卷毛和黑白脸纹。
2. 正式素材一图一造型。每次提供目标猫参考和对应的银渐层动作图。拼图可用于整套预览，交付用独立透明 PNG，逐张校准热点。
3. 大图检查姿态、透明边缘、光晕灰影和爪子是否变形。同场景不同猫并排核对，再看 25／35／45 像素三档。小档也应能分清方向和动作，箭尖可准确点选，I 形不会遮挡文字定位。原型展示图按可见轮廓等比统一大小。
