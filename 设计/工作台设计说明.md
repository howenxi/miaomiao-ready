# 工作台主界面设计
2026-11-18。用户要求先设计 Windows 轻量工作台，当前交付视觉原型，尚未实现工作台程序。

沿用奶油焦糖风格。顶部导入主题，左侧选择主题，中间八类型选择，右侧检查所选指针并调整大小与热点，下方输入、链接、拖动试用，底部应用和恢复。

待落地时校正原型中的细节：
- 系统默认主题使用系统箭头图标，生成图中猫咪为示意误差。
- I形热点在纵向中点，原型示意标在上端，须改正。
- 跟随整套大小开启时，单项滑块应显示继承值并禁用；关闭后允许单项调整。
- 右侧预览可放大，但试用区必须采用实际像素大小，避免又出现原图比例变短而导出尺寸不变的问题。
- 中间八项选择和启用控制需要清楚区分，当前原型只画出所选项，正式交互需补全启用开关。
- 主题包由skill生成，工作台负责导入、预览、调节、应用与恢复。首次备份需保留，保存状态应能恢复。
- 当前仅为设计稿，用户确认后再实现；Windows优先，Mac另行适配。
