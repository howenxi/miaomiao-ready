# 猫咪指针生图规则 v2

更新日期：2026-11-19。适用于后续所有猫咪类型。本版按用户已确认的银渐层设计整理，替代 v1 中链接点击跃起、不可用仅探头的旧要求。

## 一、参考图各自负责什么

- **真实照片决定身份**：脸型、眼形、瞳孔与虹膜比例、眼色、鼻色、嘴形、耳形、脸部花纹及左右位置、白胸白爪范围、毛长和体态。
- **已确认角色图决定同一只猫的一致性**：先确认一张，再用这张统一其余七张，不逐张重新设计一只猫。
- **设计/银渐层设计方案中的八张正式 PNG 决定动作与画风基准**：正常选择、文字输入、链接点击、不可用、忙碌中、移动画布、左右调整、上下调整。真实照片参考 JPG 不作为画风参考。
- 动作参考不决定新猫的身份。不能把银渐层的脸、绿眼睛、条纹套给三花、橘猫或其他猫；不能只给同一张模板脸换颜色。
- 用户本轮明确要求优先于本规则。修改既有图时，以用户指定的原图为动作、构图和画风依据；未要求的部分保持不变。

## 二、固定绘图风格：卡通化，不能向写实漂移

沿用当前确认的卡通鼠标皮肤：清楚的深色粗描边、圆润形体、简化的大块毛色色块，少量柔和明暗表现体积。五官用简洁线条和色块表达，缩小后仍可辨识。

**照片只用于提取长相，不用于改变渲染方式。** 不增加密集毛丝、照片质感、写实眼球和复杂光影；不改成写实插画、3D、动漫或另一套矢量风格。也不把原有柔和卡通改成完全扁平的硬色块。

“只调整脸型、五官与花色”属于局部修改：保留原图动作、身体轮廓、爪位、尾巴姿态、功能符号、相对布局和绘图风格。不能借统一角色之名重做整幅构图。脸型变化所需的局部轮廓衔接可以调整，不能连带改变全身比例。

## 三、从照片建立角色特征

绘制前记录下面内容；左右位置以画面左右明确标注，不凭品种印象补造花纹。

| 项目 | 必须观察和保留的特征 |
|---|---|
| 脸型 | 宽窄、脸颊饱满度、下巴与口鼻长度，不统一套成尖脸或幼猫脸 |
| 眼睛 | 眼形、间距、眼线、虹膜颜色、瞳孔大小；不能默认鲜绿色或统一夸张大眼 |
| 鼻嘴 | 鼻子颜色与轮廓、鼻下短线、嘴角走向；自然闭嘴不能擅自变成笑脸 |
| 花色 | 额头、眼周、双颊、耳部、身体及尾巴色块；保留明显的不对称位置 |
| 其他 | 耳形与大小、毛长、白胸白爪、身体胖瘦及其他身份特征 |

本次银渐层照片位于“银渐层设计方案/银渐层-真实照片参考.jpg”。已确认的卡通转译为：饱满圆脸、浅灰绿色虹膜配较大的黑色瞳孔、少量白色高光、灰粉色鼻子、短小自然闭嘴、白色脸颊与胸爪、淡银灰额纹及身体花色。保留卡通简化，不描绘照片中的逐根毛发。这些是这只银渐层的特征，不是其他猫的固定模板。

## 四、八种场景的动作与热点

| 文件名／场景 | 必须保留的动作、符号与热点 |
|---|---|
| 正常选择.png | 坐姿，两只前爪抱住朝左上的箭头。左上箭尖完整露出，热点在箭尖。 |
| 文字输入.png | 左侧 I 形，右下仅露猫头和两只前爪。长度与布局按已确认银渐层成品，不自行拉长或改成全身抱 I。猫脸避开定位区，热点在 I 形中点。 |
| 链接点击.png | **坐姿**，后脚与坐姿轮廓清楚，一只前爪向左上伸出点击，另一爪靠近身前。爪尖附近可有少量点击提示线，热点在爪尖，不在提示线上。不能改回腾空跃起。 |
| 不可用.png | **端坐抱牌**，双爪从左右两侧抱住胸腹前的红色禁止符号，后脚自然落地，尾巴靠身侧。禁止环及斜杠完整清楚，热点在环中心。不能仅露猫头搭在环上，也不能把后脚向前摊开露肉垫。 |
| 忙碌中.png | 闭眼蜷睡，前爪并排，尾巴绕到身前，头顶三块橙色进度标呈弧形。保持睡姿与闭眼；统一角色时只调整脸颊、口鼻、耳形与花色，不强行换成睁眼脸。热点取主体中心。 |
| 移动画布.png | 保留斜向伸展动作，一只展开的大爪向左上伸出，粉色肉垫朝前，可保留原图运动短线。热点在大爪中心。与坐姿的链接点击明确区分。 |
| 左右调整.png | **身体伏低趴在细横向双箭头上**，前爪分开搭住箭杆，胸腹贴近箭杆，有真实承托关系。整只猫含爪和尾巴不超过左右箭尖，两端留少量余量。不能只横向压窄猫，不能让猫悬在箭头上方，也不能把细箭头改成巨大的厚块。热点在双箭头中点。 |
| 上下调整.png | 猫位于竖向双箭头右侧，双爪扶抱箭杆，保留原图身体姿势，上下箭尖完整露出。热点在双箭头中点。 |

允许新设计在用户确认前适度调整头部倾斜、抓握位置和坐姿角度，但不能破坏上述动作。用户要求保留原图造型时，不主动进行这些调整。

## 五、生成顺序与局部修改约束

1. 保存用户原照到该猫的设计方案文件夹，使用明确的参考照片文件名；不覆盖或删除原照。
2. 根据照片记录角色特征。先选一个场景生成一张预览，默认正常选择；用户指定其他场景时按指定执行。
3. 向生成工具分别说明：哪张是待编辑原图，哪张是身份参考，哪张是画风或动作参考。尤其写明“照片只决定特征，原图决定绘图风格”。
4. 先向用户展示这一张。用户确认后才同步其余七张；用户已明确授权整套更新时直接继续。
5. 同步时每张使用对应动作原图加已确认角色图，明确“只改脸型、五官和花色；保持原动作、身体、符号和画风”。不要只给角色参考而让工具自由生成姿势。
6. 检查整套后替换正式 PNG。绘制和造型修改使用图像编辑工具；程序仅用于裁透明边、等比缩放、居中和文件编码，不用挤压图像代替姿势调整。

## 六、尺寸、透明背景与验收

- 一图一个造型，交付独立透明 PNG。不得带文字、卡片底板、背景色、棋盘格、外部阴影、光晕或热点标记。
- 设计图统一 **560×560 像素透明画布**；先去掉多余透明留白，再按完整可见图案最长边 **512 像素**等比缩放并居中。完整图案包括功能符号及需要保留的提示线，不只测猫头。不得拉伸宽高或裁掉耳朵、尾巴、爪子及箭尖。
- 同画布尺寸不等于同图案尺寸，必须核对有效透明轮廓。不同姿势的宽高比例自然不同，不强行填满正方形。
- 逐张与原动作图核对：身体、爪位、尾巴、符号和构图有没有被擅改；与原照及确认角色图核对：是否仍是同一只猫，眼色和花纹方向是否正确。
- 并排查看整套：画风、脸型、五官比例和花色一致；忙碌款保留闭眼，其余表情随动作自然变化。
- 检查透明边缘残留、光晕、变形或多余肢体、断开的符号。查看25／35／45像素下的辨识度、箭头方向和文字定位遮挡。
- 热点以最终图片实际坐标测量。设计 PNG 更新不等于 CUR、安装包或系统指针已更新；没有重新导出和验证时不得宣称已同步安装效果。560画布与512图案边长是设计素材规范，不代表系统鼠标的显示尺寸。

## 七、文件组织与完成标准

设计目录按猫分类，例如“银渐层设计方案”“三花设计方案”。每个文件夹保留八张正式 PNG，名称按上表统一；实际只找到部分既有素材时先查其他历史素材目录，不凭当前配置就断言只有四张，也不拿其他猫的图补数。

原始照片单独明确命名。预览阶段可暂存预览图，正式采用后替换对应正式文件并清理重复预览，不保留两张相同用途的成品让用户混淆。不擅自删除其他有效方案或程序依赖的素材源文件。

完成时说明具体修改、保存位置和未完成范围。当前所有修改默认仅保留本地，不自动暂存或提交 Git，不提交 GitHub；用户明确同意后才操作。
